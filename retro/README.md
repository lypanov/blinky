# retro

NESTang and other retro-FPGA work. **Not** under `primer20k/`.

- [`nestang/`](https://github.com/nand2mario/nestang) — git submodule pinned at tag **v0.4** (last Primer 20K support)
- [`overlay/`](overlay/) — Dock CST patch applied on top of v0.4
- [`nestang_uart_load.py`](nestang_uart_load.py) — one-shot UART ROM loader
- [`nestang.md`](nestang.md) — bring-up notes
- HDMI stills in this directory (palette / nestest / Alter Ego)

GPL (fpganes lineage). Do not commit `.nes` or `.fs`. SRAM load only.
